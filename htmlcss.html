A 30‑Day Hands‑On Coding Quest

For Teenagers 12–15 · Build real websites · Learn by doing

📘 30 sessions ⏱ 1–2 hrs each 💻 VS Code

👋 Welcome, Future Web Creator!

This book is your personal guide to learning HTML and CSS — the two core languages that power every website you see. You don't need any previous coding experience. Just bring your curiosity, a computer, and a willingness to experiment.

Every day for the next 30 sessions (about 1–2 hours each), you'll learn something new and immediately build something real. By the end, you'll be able to create beautiful, responsive websites from scratch — and you'll have a portfolio of projects to show off.

🌟 Pro tip for teens: Code is like learning a new language — you get better by speaking it every day. Type every example yourself. Break things on purpose. That's how you learn!

📖 How to Use This Book

  • Read the lesson – understand the concept.
  • Type the code – never copy-paste. Typing builds muscle memory.
  • Do the exercises – each session has a mini-challenge.
  • Save your work – create a folder called my-web-journey and save each day's file.
  • Experiment – change colors, tweak layouts, make it yours.
🎯 Did you know? The first website ever made is still online! It was created by Tim Berners‑Lee in 1991. You can visit it at info.cern.ch. It's just text and links — no CSS!

🌱 Week 1 · HTML Foundations

Day 1 Hello, World! – Your First Page ⏱ 1 hr
🎯 Goals: Set up VS Code · Create an HTML file · Understand tags · See your page in a browser.

📌 What is HTML?

HTML (HyperText Markup Language) is the skeleton of every webpage. It uses tags like <h1> and <p> to structure content. Think of it like building with Lego blocks — each tag is a block with a specific purpose.

🔧 Setup

  1. Open VS Code. Create a new folder called my-web-journey.
  2. Inside it, create a file called index.html.
  3. Type the following exactly (don't copy-paste — type it!):
<!DOCTYPE html>
                <html>
                <head>
                <title>My First Page</title>
                </head>
                <body>
                <h1>🚀 Hello, World!</h1>
                <p>This is my first webpage. I'm learning HTML!</p>
                </body>
                </html>

👀 View it!

Right‑click the file in VS Code and select "Open with Live Server" (if you have the extension). Or just double‑click the file to open it in your browser. You should see your page!

✏️ Challenge: Change the <h1> text to your name. Add a second <p> paragraph about your favorite hobby. Save and refresh the browser to see your changes.
💡 The <!DOCTYPE html> tells the browser "this is HTML5" — the latest version of HTML.
Day 2 Structure – Head & Body ⏱ 1 hr
🎯 Goals: Understand the <head> vs <body> · Meta tags · Title · Basic structure.

🧩 The Two Main Parts

  • <head> – contains metadata (information about the page). Things like the title, character set, and links to CSS files. Not visible on the page.
  • <body> – contains everything that is visible on the page: text, images, buttons, etc.

📝 Try This

Update your index.html to include these meta tags:

<!DOCTYPE html>
                <html lang="en">
                <head>
                <meta charset="UTF-8" />
                <meta name="viewport" content="width=device-width, initial-scale=1.0" />
                <title>My Awesome Site</title>
                </head>
                <body>
                <h1>Welcome to My Site</h1>
                <p>This page is optimized for all devices!</p>
                </body>
                </html>
🔍 The viewport meta tag makes your page look good on phones and tablets. Always include it!
⚠️ Common mistake: Forgetting the closing </head> or </body> tags. Always double‑check your nesting!
Day 3 Text & Lists ⏱ 1–1.5 hr
🎯 Goals: Headings · Paragraphs · Bold/Italic · Ordered & Unordered lists.

📝 Text Tags

  • <h1> to <h6> – headings (h1 is biggest)
  • <p> – paragraph
  • <strong> – bold text
  • <em> – italic (emphasis)
  • <br> – line break (self‑closing)
  • <hr> – horizontal rule (separator)

📋 Lists

  • <ul> – unordered list (bullets)
  • <ol> – ordered list (numbers)
  • <li> – list item (inside a list)

💻 Code Example

<h1>My Favorite Things</h1>
                <p>Here are some of my <strong>favorite</strong> hobbies:</p>
                <ul>
                <li>🎮 Gaming</li>
                <li>📚 Reading</li>
                <li>💻 Coding</li>
                </ul>
                <h2>Top 3 Games</h2>
                <ol>
                <li>Minecraft</li>
                <li>Roblox</li>
                <li>Fortnite</li>
                </ol>
✏️ Challenge: Create a page about your "Top 5 Movies" or "My Dream Vacation". Use headings, paragraphs, bold, italic, and both types of lists. Make it look organized!
Day 4 Links & Images ⏱ 1–1.5 hr
🎯 Goals: Create hyperlinks with <a> · Add images with <img> · Use alt text.

🔗 Links

The <a> (anchor) tag creates a link. The href attribute specifies the destination. 

<a href="https://www.google.com">Go to Google</a>
                <a href="#section2">Jump to Section 2</a> <!-- internal link -->
                <a href="mailto:me@example.com">Email Me</a>

🖼️ Images

The <img> tag is self‑closing. It needs src (source) and alt (alternative text for accessibility). 

<img src="https://picsum.photos/400/300" alt="A random image" />
                <img src="my-photo.jpg" alt="A picture of me" width="300" />
⚠️ Always use alt! It helps screen readers and shows text if the image doesn't load.
✏️ Challenge: Create a "My Favorite Places" page. Add 3–4 images (use https://picsum.photos/200/150 for random pics). Link each image to a website about that place. Use target="_blank" to open links in a new tab.
Day 5 Tables & Forms ⏱ 1.5 hr
🎯 Goals: Build tables with <table> · Create a simple form with <input> and <button>.

📊 Tables

Tables use <tr> (row), <th> (header cell), and <td> (data cell). 

<table border="1">
                <tr>
                <th>Name</th><th>Age</th><th>City</th>
                </tr>
                <tr>
                <td>Alice</td><td>14</td><td>NYC</td>
                </tr>
                <tr>
                <td>Bob</td><td>13</td><td>LA</td>
                </tr>
                </table>

📝 Forms

<form action="/submit" method="post">
                <label for="name">Your Name:</label>
                <input type="text" id="name" name="name" />
                <label for="email">Email:</label>
                <input type="email" id="email" name="email" />
                <button type="submit">Send!</button>
                </form>
✏️ Challenge: Make a "Class Schedule" table (Mon–Fri, 3–4 subjects). Then add a "Contact Me" form with name, email, and a message box (<textarea>).
💡 The action attribute in a form tells the browser where to send the data. For now, we'll keep it as # (same page).

🎨 Week 2 · CSS Basics

Day 6 Colors, Fonts & Text ⏱ 1–1.5 hr
🎯 Goals: Understand CSS syntax · Change colors · Font families · Text alignment & decoration.

🎨 What is CSS?

CSS (Cascading Style Sheets) is the style layer of the web. It controls colors, fonts, layout, animations — everything visual. CSS works by selecting HTML elements and applying properties with values.

🔤 Syntax

selector {
                property: value;
                property: value;
                }

💻 Try It

Add a <style> tag inside <head>: 

<style>
                body {
                background-color: #f0f4ff;
                font-family: 'Segoe UI', Arial, sans-serif;
                }
                h1 {
                color: #1e40af;
                font-size: 2.5rem;
                text-align: center;
                }
                p {
                color: #334155;
                line-height: 1.8;
                }
                </style>
🎯 Color tip: Use color for text color, background-color for backgrounds. Try hex codes like #ff6b6b or named colors like tomato.
⚠️ Don't forget the semicolon! Every CSS declaration must end with a ;.
Day 7 The Box Model ⏱ 1.5 hr
🎯 Goals: Understand margin, border, padding, content · Use width, height, box-sizing.

📦 Every Element Is a Box

In CSS, every HTML element is a rectangular box made of:

  • Content – the text or image inside.
  • Padding – space inside the border.
  • Border – the edge around the padding.
  • Margin – space outside the border.
.card {
                width: 300px;
                padding: 20px;
                border: 3px solid #2563eb;
                margin: 30px auto;
                background: white;
                border-radius: 16px;
                box-shadow: 0 8px 24px rgba(0,0,0,0.1);
                }
💡 box-sizing: border-box; makes padding and border included in the width/height. It's a game‑changer! Add it to everything with * { box-sizing: border-box; }.
📐 The total width of an element = width + padding + border + margin (when box-sizing: content-box).
Day 8 Flexbox – One‑Dimensional Layout ⏱ 1.5–2 hr
🎯 Goals: Use display: flex · justify-content · align-items · flex-direction · gap.

⚡ Flexbox = Powerful Alignment

Flexbox is a layout mode that makes it easy to align and distribute items in a row or column. 

.container {
                display: flex;
                flex-direction: row;        /* row | column */
                justify-content: center;    /* horizontal alignment */
                align-items: center;        /* vertical alignment */
                gap: 16px;                  /* space between items */
                }

                .item {
                padding: 20px;
                background: #dbeafe;
                border-radius: 12px;
                }

🧪 Experiment

Create a container with 3 boxes inside. Try: justify-content: space-between, space-around, flex-end.

✏️ Challenge: Build a "Navigation Bar" with flex. Put a logo on the left and 3 links on the right. Use justify-content: space-between.
Day 9 Grid – Two‑Dimensional Layout ⏱ 1.5–2 hr
🎯 Goals: Use display: grid · grid-template-columns · grid-template-rows · gap · grid-column / grid-row.

🧩 CSS Grid = 2D Power

Grid is perfect for laying out entire pages. You define columns and rows, then place items inside. 

.grid-container {
                display: grid;
                grid-template-columns: 1fr 2fr 1fr;  /* 3 columns */
                grid-template-rows: 100px 200px;
                gap: 20px;
                }

                .item-1 {
                grid-column: 1 / 3;  /* span from column 1 to 3 */
                }
📐 The fr unit means "fraction" — it distributes available space. 1fr 2fr means the second column is twice as wide as the first.
💡 Grid and Flexbox work great together! Use Grid for page‑level layout and Flexbox for components inside.
Day 10 Positioning & Z‑Index ⏱ 1.5 hr
🎯 Goals: position: static · relative · absolute · fixed · sticky · z-index.

📍 Positioning Types

  • static – default. Stays in the normal flow.
  • relative – moves relative to its normal position.
  • absolute – removed from flow; positioned relative to nearest positioned ancestor.
  • fixed – positioned relative to the viewport (stays in place on scroll).
  • sticky – hybrid: relative until scroll threshold, then fixed. 
.parent {
                position: relative;
                height: 300px;
                background: #e9edf5;
                }

                .child {
                position: absolute;
                top: 50%;
                left: 50%;
                transform: translate(-50%, -50%);
                }

                .sticky-nav {
                position: sticky;
                top: 0;
                background: white;
                z-index: 100;
                }
⚠️ z-index only works on positioned elements (relative, absolute, fixed, sticky). It controls stacking order.

⚡ Week 3 · Intermediate CSS

Day 11 Responsive Design & Media Queries ⏱ 1.5–2 hr
🎯 Goals: Make sites work on all screen sizes · @media queries · Breakpoints · Mobile‑first design.

📱 What is Responsive Design?

A responsive website adapts to the screen size — phone, tablet, desktop. We use media queries to apply different styles at different widths. 

/* Mobile first — styles for all screens */
                .container {
                display: grid;
                grid-template-columns: 1fr;
                }

                /* Tablet and up */
                @media (min-width: 600px) {
                .container {
                grid-template-columns: 1fr 1fr;
                }
                }

                /* Desktop and up */
                @media (min-width: 900px) {
                .container {
                grid-template-columns: 1fr 1fr 1fr;
                }
                }
📐 Common breakpoints: 600px (tablet), 900px (desktop), 1200px (large desktop). Start with mobile styles, then add layers with min-width.
📱 Over 60% of web traffic comes from mobile devices. Responsive design isn't optional — it's essential!
Day 12 Transitions & Animations ⏱ 1.5 hr
🎯 Goals: Use transition for smooth changes · @keyframes for animations · animation properties.

✨ Transitions

Transitions make property changes smooth over time.

.btn {
                background: #2563eb;
                padding: 12px 24px;
                transition: background 0.3s ease, transform 0.2s ease;
                }

                .btn:hover {
                background: #1e40af;
                transform: scale(1.05);
                }

🎬 Keyframe Animations

@keyframes bounce {
                0% { transform: translateY(0); }
                50% { transform: translateY(-20px); }
                100% { transform: translateY(0); }
                }

                .bouncy {
                animation: bounce 1s ease-in-out infinite;
                }
✏️ Challenge: Create a button that changes color and grows on hover. Then add a spinning or bouncing element using @keyframes.
Day 13 CSS Variables (Custom Properties) ⏱ 1 hr
🎯 Goals: Declare variables with --name · Use var(--name) · Theming & maintainability.

🎨 What Are CSS Variables?

They let you store values (colors, sizes, etc.) and reuse them everywhere. Change the variable once, and it updates everywhere. 

:root {
                --primary: #2563eb;
                --secondary: #f59e0b;
                --spacing: 16px;
                --radius: 12px;
                }

                .card {
                background: var(--primary);
                padding: var(--spacing);
                border-radius: var(--radius);
                color: white;
                }

                .warning {
                background: var(--secondary);
                }
💡 :root is a pseudo‑class that matches the <html> element. It's perfect for global variables.
🎯 CSS variables are supported in all modern browsers and make theming super easy — dark mode is just a few variable swaps!
Day 14 Pseudo‑classes & Pseudo‑elements ⏱ 1–1.5 hr
🎯 Goals: :hover · :focus · :nth-child() · ::before · ::after.

🪄 Pseudo‑classes

Target elements in a specific state.

a:hover { color: red; }
                input:focus { border-color: blue; }
                li:nth-child(2) { background: #f0f4ff; }
                .card:first-child { margin-top: 0; }

✨ Pseudo‑elements

Style parts of an element.

h1::before {
                content: "⭐ ";
                font-size: 1.8rem;
                }
                p::first-letter {
                font-size: 3rem;
                font-weight: bold;
                color: #2563eb;
                }
✏️ Challenge: Style every odd‑numbered list item with a different background. Add a star icon before each heading using ::before.
Day 15 Advanced Selectors ⏱ 1–1.5 hr
🎯 Goals: Attribute selectors · Child combinators · Sibling selectors · Specificity.

🎯 Powerful Selectors

  • input[type="text"] – attribute selector
  • .parent > .child – direct child
  • .sibling + .next – adjacent sibling
  • .sibling ~ .all – general sibling
/* All text inputs */
                input[type="text"] {
                border: 2px solid #d1d5db;
                }

                /* Direct children of .nav */
                .nav > li {
                display: inline-block;
                }

                /* Paragraph after a heading */
                h2 + p {
                font-weight: bold;
                }
⚡ Specificity hierarchy: Inline styles > IDs > Classes > Elements. Try to use classes most of the time — they're the sweet spot.

🚀 Week 5 · Advanced & Best Practices

Day 21 CSS Frameworks (Bootstrap / Tailwind) ⏱ 1.5–2 hr
🎯 Goals: Learn what frameworks are · Try Bootstrap or Tailwind · Build a component.

⚡ What is a CSS Framework?

A framework is a library of pre‑written CSS classes that speed up development. Two popular ones:

  • Bootstrap – has ready‑made components (navbars, cards, modals, etc.). Good for quick prototypes.
  • Tailwind CSS – "utility‑first" — you compose styles directly in your HTML using classes like bg-blue-500, text-white, p-4.

🔧 Try Bootstrap

Add this to your <head>:

<link
                href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"
                rel="stylesheet"
                />

Now use classes like btn btn-primary, container, row, col-4.

💡 Frameworks are tools, not crutches. Learn vanilla CSS first, then use frameworks to save time. You'll be a better developer because you understand what's happening under the hood.
Day 22 Forms & Input Validation ⏱ 1.5 hr
🎯 Goals: Build accessible forms · HTML5 validation · Styling inputs · :valid / :invalid.

📝 Better Forms

<form>
                <label for="email">Email</label>
                <input
                type="email"
                id="email"
                name="email"
                placeholder="you@example.com"
                required
                />
                <label for="password">Password (min 8 chars)</label>
                <input
                type="password"
                id="password"
                name="password"
                minlength="8"
                required
                />
                <button type="submit">Sign Up</button>
                </form>

🎨 Style validation states

input:valid {
                border-color: #22c55e;
                }
                input:invalid {
                border-color: #ef4444;
                }
                input:focus {
                outline: 3px solid #93c5fd;
                }
⚠️ Client‑side validation is for UX, not security! Always validate on the server too (but that's for later).
Day 23 Accessibility & Semantic HTML ⏱ 1.5 hr
🎯 Goals: Write inclusive code · Use semantic tags · ARIA basics · Keyboard navigation.

♿ Why Accessibility Matters

The web is for everyone. People use screen readers, keyboard navigation, and other assistive technologies. We can build sites that work for all.

🧱 Semantic HTML

Use these instead of generic <div>:

  • <header> – page header
  • <nav> – navigation
  • <main> – primary content
  • <section> – thematic grouping
  • <article> – self‑contained content
  • <aside> – sidebar or complementary content
  • <footer> – page footer
🔑 Always use alt text on images. Use aria-label on interactive elements when needed. And make sure your site is fully keyboard‑navigable.
🌍 The web is used by over 1 billion people with disabilities. Accessible design is better design for everyone.
Day 24 Performance & Optimization ⏱ 1.5 hr
🎯 Goals: Optimize images · Minify code · Use loading="lazy" · Reduce HTTP requests.

⚡ Make Your Site Fast

  • Image optimization: Use WebP format, compress images, set width and height.
  • Lazy loading: <img loading="lazy" ... /> loads images only when they're about to appear on screen.
  • Minify CSS: Remove unnecessary spaces and comments. VS Code extensions can do this.
  • Combine files: Use one CSS file instead of many.
  • Use CDN: Load libraries from a CDN for faster delivery.
📊 Check performance with Chrome DevTools → Lighthouse tab. It gives you a score and suggestions to improve.
Day 25 Debugging with DevTools ⏱ 1.5 hr
🎯 Goals: Use Chrome DevTools · Inspect elements · Edit CSS live · Debug layout issues · Console.

🔧 Your Best Friend: DevTools

Open DevTools with F12 or Ctrl+Shift+I (or Cmd+Option+I on Mac).

  • Elements panel: Inspect the HTML and CSS of any element. You can edit styles live and see changes instantly.
  • Styles pane: See all CSS rules applied to an element, including inherited styles. Toggle properties on/off.
  • Computed pane: See the final computed values (including box model dimensions).
  • Console: Type JavaScript to test things (we'll use this later).
  • Lighthouse: Audit performance, accessibility, SEO.
💡 Pro debugging tip: When something doesn't look right, inspect it. Check if the selector is actually matching. Look for overridden styles. Use !important sparingly (almost never).

📖 Glossary

HTML HyperText Markup Language — the structure of web pages.
CSS Cascading Style Sheets — the style and layout layer.
Tag An HTML element marker, e.g. <p>.
Attribute Extra information in a tag, e.g. src="...".
Selector CSS pattern that targets elements, e.g. .class.
Property CSS styling attribute, e.g. color.
Flexbox CSS layout model for one‑dimensional alignment.
Grid CSS layout model for two‑dimensional layouts.
Media Query CSS rule that applies styles based on screen size.
Responsive Design that adapts to different screen sizes.
Semantic HTML elements that convey meaning, e.g. <article>.
Accessibility Designing for people with disabilities.
DevTools Browser tools for debugging and inspecting code.
Framework Pre‑built CSS library like Bootstrap or Tailwind.
